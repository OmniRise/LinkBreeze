# TrueNAS (ix-dev community train)

Canonical source for the TrueNAS app definition. Target: a PR against
`truenas/apps` (ix-dev/community/linkbreeze) from the
`OmniRise/LinkBreeze-TrueNAS-App` fork, branch `feat/linkbreeze-app`.
While that PR is open, `packaging-sync.yml` keeps the fork branch updated on
every release and the upstream PR refreshes automatically. After upstream
merges, the same sync keeps our fork aligned; config-shape changes (new env
vars, ports, storage options) still need a PR against `truenas/apps`.

The directory mirrors the upstream layout exactly
(`ix-dev/community/linkbreeze/`) so the sync step is a plain copy:

- `app.yaml` / `item.yaml` / `ix_values.yaml` / `questions.yaml` / `README.md`
- `templates/docker-compose.yaml`, `templates/test_values/`, `templates/library/`
  (`library` and `item.yaml` are generated by truenas/apps tooling; regenerating
  locally: run `uv run .github/scripts/ci.py --app linkbreeze --train community`
  in a checkout of the fork, then copy the files back here)

On each release fold, bump:

1. `ix_values.yaml`: image tag and digest (`v<VERSION>@sha256:...`, multi-arch
   index digest from `docker buildx imagetools inspect ghcr.io/omnirise/linkbreeze:v<VERSION>`)
2. `app.yaml`: `app_version: <VERSION>` (no `v` prefix)
